## 기준선 판정

- 의존성 복구와 production build는 성공했다.
- lint와 typecheck는 실패하지만 모든 진단에 파일, 행, 해결 phase를 지정했다.
- P0-11에서 배포 preset을 Vercel 기준으로 확정한 뒤 build 경고를 다시 확인한다.
- 누락 라우트를 임시 빈 화면으로 만들어 타입만 숨기지 않고, 각 기능 phase에서 권한·데이터 상태와 함께 구현한다.
